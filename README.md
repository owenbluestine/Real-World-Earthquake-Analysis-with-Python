This is a project I created for Computer Aided Analysis (ESC 113) at Borough of Manhattan Community College. 
The goal of the report was to organize and analyze real-world data in a manner which would be useful in the field of engineering. 
The data used in this project can be found in the repository under the file name EQDATA.csv. 
All earthquakes apart of the data in this report occurred in the month of September 2026.
